# Data policy

The public demo does not contain company data. Run `python scripts/generate_demo_data.py` to create `data/demo.csv` locally. The generated file is ignored by Git and contains only synthetic products (`P001`, `P002`, ...), generic categories, and simulated daily sales and stock.

The synthetic data is for pipeline testing and method demonstration. It must not be described as real-world pretraining evidence or as a proxy for any employer's data.
